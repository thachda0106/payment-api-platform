# Get Documentation

Fetch the latest documentation for a library or framework.

## Steps

1. **Resolve Library** — Find the correct library identifier
2. **Fetch Docs** — Retrieve the latest documentation
3. **Summarize** — Extract key installation, configuration, and usage patterns relevant to this project

## Usage

Provide the library name as input:
- `@nestjs/common`
- `typeorm`
- `react`
- Any npm/pip/cargo package name

## Notes

- Use documentation retrieval tools if available (e.g., Context7 MCP)
- If no documentation tool is available, use web search
- Summarize for the project's specific tech stack and patterns
- Focus on API details, configuration, and integration patterns
