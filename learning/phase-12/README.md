# Phase 12 — Cloud & Platform Engineering

> **Duration**: 6-8 weeks | **Prerequisites**: Phase 1 (OS/Networking)
>
> **Goal**: Deploy the payment platform on Kubernetes in AWS using Terraform for infrastructure, ArgoCD for GitOps, and Istio for service mesh.

## Modules

| Module | Topics | Hours |
|--------|--------|:-----:|
| 01 | Docker (namespaces/cgroups/UnionFS), Kubernetes (pods/deployments/services/HPAs) | 20h |
| 02 | Helm, Istio Ambient (mTLS/traffic splitting), ArgoCD (GitOps) | 15h |
| 03 | Terraform, AWS (EKS/Aurora/MSK/ElastiCache), Multi-Region, Cost | 15h |
| Mini Project | Platform Infrastructure | 15h |

## Resources

- **Book**: "Docker Deep Dive" (Poulton), "Kubernetes in Action" (Luksa), "Terraform: Up & Running" (Brikman)
- **Practice**: Killercoda (free K8s labs), AWS Free Tier
