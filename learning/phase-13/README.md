# Phase 13 — Observability

> **Duration**: 3-4 weeks | **Prerequisites**: Phase 12 (Cloud & Platform)
>
> **Goal**: Instrument a polyglot microservices platform with unified logging, metrics, and tracing. Define SLOs, build dashboards, and respond to incidents.

## Modules

| Module | Topics | Hours |
|--------|--------|:-----:|
| 01 | Three Pillars (logs/metrics/traces), Prometheus/PromQL, Grafana, OTel | 15h |
| 02 | SLI/SLO/SLA, Error Budgets, Alerting, Incident Response | 10h |
| Mini Project | Observability Platform & Dashboards | 10h |
