# Phase 14 — Security Engineering

> **Duration**: 4-6 weeks | **Prerequisites**: Phase 10 (Dist Systems), Phase 12 (Platform)
>
> **Goal**: Secure a payment platform against real threats: implement OAuth2/OIDC, JWT with key rotation, RBAC, encryption at rest and in transit, and map PCI DSS requirements to architecture.

## Modules

| Module | Topics | Hours |
|--------|--------|:-----:|
| 01 | Cryptography, TLS 1.3, OAuth2/OIDC, JWT Deep Dive | 15h |
| 02 | RBAC/ABAC, Secrets, PCI DSS, Threat Modeling, OWASP | 15h |
| Mini Project | Secure Authentication Service | 10h |

## Resources

- **Book**: "Web Application Security" (Hoffman)
- **Doc**: OWASP Top 10, PCI DSS v4.0, OAuth 2.0 RFC 6749
