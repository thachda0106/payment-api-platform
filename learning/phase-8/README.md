# Phase 8 — FastAPI + NestJS + Chi

> **Duration**: 3-4 weeks | **Prerequisites**: Phase 4 (Python), Phase 5 (Go), Phase 6 (TypeScript/Node)
>
> **Goal**: Build production services in all three remaining frameworks with correct patterns for validation, database access, middleware, and testing.

## Study Plan

| Week | Framework | Topics | Hours |
|------|-----------|--------|:-----:|
| 1 | FastAPI | ASGI, routes, DI, Pydantic v2, SQLAlchemy async, testing | 15h |
| 2 | NestJS | Modules, controllers, providers, guards/interceptors/pipes, Prisma | 15h |
| 3 | Chi | Router, middleware chains, sqlc codegen, database/sql | 10h |
| 4 | Mini Projects | One microservice per framework | 12h |
